# report-generator

## Prerequisites
1. You need to have a Gemini API key (or use other AI models)
2. modify `.env.example` to add the `API_KEY`, `AI_MODEL`, and `GIT_AUTHOR`

## Libraries used:
1. [Typescript](https://www.typescriptlang.org/)
2. [Clack](https://bomb.sh/docs/clack/basics/getting-started/)
4. [TanStack AI SDK](https://tanstack.com/ai/latest)
5. [React](https://react.dev/)

## Installation:

> Highly recommended to use `bun` instead of `nodejs`

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.1. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
